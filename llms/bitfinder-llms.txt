# Awair (Bitfinder, Inc.)

> Bitfinder, Inc., d/b/a Awair, builds indoor air quality (IAQ) monitors (Awair Element, Awair Omni) and a cloud platform. The Awair Home & OAuth Developer API gives developers programmatic, OAuth-authorized access to a user's devices and their air-data (Awair Score plus temperature, humidity, CO2, VOC, and PM2.5) at latest, raw, 5-minute-average, and 15-minute-average granularity.

## APIs
- [Awair Home & OAuth Developer API](https://docs.developer.getawair.com/): Cloud API at https://developer-apis.awair.is/v1 — user profile, devices, air-data.
